# Development

Keep work in this directory, ready to reuse when the system is replaced.

```sh
./src/PROJECT/  # use YYYY-MM-DD/ for temporary work
./opt/
./lib/
./bin/
```

## Documentation

Start with `AGENTS.md`. Split large sections into child files.

```text
AGENTS.md
├── PROMPT.md — thoughts
├── PLAN.md — implementation delta
└── DESIGN.md — shape
    └── SPEC.md — specification
```
