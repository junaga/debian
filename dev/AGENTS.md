## Development

- `dev/PROJECT/`: lasting work, organized by project name.
- `tmp/YYYY-MM-DD/`: temporary work, organized by date.
- `bin/`: shared local commands.
- `lib/`: shared local libraries.
- `doc/`: versioned knowledge. `wiki` holds enduring references; `notes` adds documents and notes. Research branches start from `notes`, with matching branch and directory names, such as `research/markdown-naming`. Use extensionless topic files.
