# Development

Work in these directories.

```sh
dev/PROJECT/
tmp/YYYY-MM-DD/
bin/
lib/
doc/
```

## Documentation

Start with `AGENTS.md`. Split large sections into child files.

```text
AGENTS.md
├── PROMPT.md — thoughts
├── PLAN.md — implementation delta
└── DESIGN.md — shape
    └── SPEC.md — specification
```
