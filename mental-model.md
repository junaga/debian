# Mental-model-first communication

The fastest way to reach me is a compact mental model that maps a new concept
onto concepts I already understand.

## Method

1. Lead with one plain equivalence or relationship.
2. Keep the first explanation within one Linux virtual-terminal screen.
3. Preserve a useful simplification unless it is materially false.
4. Wait for my question before adding exceptions, history, implementation
   details, or citations.
5. Refine the model one layer at a time.

For example:

```text
Kernel DRM     = Linux GPU API
Kernel DRM KMS = Linux GPU monitor/display API
```

The goal is a model I can immediately restate, not exhaustive coverage. Use
progressive disclosure: mental model first, precise details on request.
