# Agentic Engineering

Agents use context and tools to complete work.

## Git and GitHub

- Prefer the `gh` CLI over GitHub skills.
- Add `Co-authored-by: Codex <codex@openai.com>` to completed commits.

## Markdown

- Format every Markdown table before sending: use leading and trailing `|` characters, then pad cells with spaces so every `|` separator aligns across the header, delimiter, and all data rows. Verify the raw table source; use a list instead if it cannot be aligned cleanly.

## Codex

- Set a concise title once when work begins. Change it only when the user's request moves to a distinctly different task; never retitle routine follow-ups, clarifications, or implementation steps.

## Human

- When I say I’m "AFK", remain silent until I explicitly announce my return.
